# 净映（ClearPlay）

当前版本：**0.17.0**。面向腾讯视频和爱奇艺网页版的 Chromium Manifest V3 扩展，过滤已识别的暂停广告、推荐流广告，并处理腾讯首页轮播广告。无需构建即可加载。

## 功能与边界

| 范围 | 当前处理方式 |
| --- | --- |
| 腾讯视频暂停广告 | 隐藏已知普通、分屏、全屏及宽屏广告容器，暂停专用广告素材，尝试原生关闭以恢复正片布局。 |
| 腾讯视频推荐流 | 根据卡片中的明确广告标记隐藏整张广告卡片，并停止其音视频。 |
| 腾讯视频首页轮播 | 在页面读取特定 getPage 接口响应时，清空 pc_carousel 模块的 children_list.ad_list.cards；保留正常 list.cards。另尝试已知轮播广告关闭按钮作为兜底。 |
| 爱奇艺暂停广告 | 处理播放器内已知普通及全屏暂停广告，并尝试原生关闭按钮。 |
| 爱奇艺推荐及轮播推广 | 处理已识别的广告卡片、游戏推广、图片广告、独立视频广告、横排小卡片、图文横条及带明确广告链接特征的轮播缩略卡。 |
| 爱奇艺广告占位 | 在已确认列表结构内收起仅含广告的占位，不移动或复制正常视频节点。 |

一个开关控制两个网站，默认开启；设置保存在本机，并同步到已打开的支持页面。通过 DOM 变化和媒体事件处理动态广告，没有定时全页扫描。原生关闭有次数限制。

关闭过滤会撤销可恢复的元素隐藏、停止媒体干预和关闭重试，但不会主动恢复广告播放，也不会重新创建已被原生关闭或从响应数据中过滤的广告。

**限制：**不处理贴片广告、iframe 或 Shadow DOM 内的广告、直接绘入正片画面的广告及未识别的新模板。规则依赖网站结构，网站更新后可能失效或出现误匹配。隐藏、暂停和响应过滤均不保证阻止广告下载或计费。

腾讯轮播处理包装页面的 fetch 和 XMLHttpRequest 响应读取，仅针对已限定的接口及模块，不阻止整个接口请求；fetch 的直接流、blob 等其他读取方式未过滤。关闭后取消后续页面的相关脚本注册；已注入页面根据开关停止过滤。首次安装、更新扩展或在关闭状态打开页面后重新开启时，请刷新腾讯页面，以使渲染前脚本生效并重新获取轮播数据。“连接并修复当前页”只重新注入普通内容脚本和样式。

## 安装与更新

最低 Chromium 主版本为 **111**（见 manifest.json）；支持允许加载本地扩展的 Chrome / Edge。

1. 将项目下载或克隆到本地；使用 ZIP 时先解压。
2. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`，开启开发者模式。
3. 选择“加载已解压的扩展程序”，选中直接包含 `manifest.json` 的目录。
4. 确认浏览器登记版本为 **0.17.0**，并允许扩展持续访问腾讯视频和爱奇艺；仅“点击时”访问不能保证自动运行。
5. 刷新已打开的支持页面。正常使用无需每次点击插件。

更新本地文件后，先在扩展管理页点击“重新加载”，再刷新已打开的网站。手动加载的扩展不会通过 GitHub 自动更新。若弹窗提示版本未同步，请检查浏览器登记版本及页面脚本版本。

仅使用插件无需 Node.js、npm 或 Playwright；这些工具用于开发测试。

## 权限与隐私

- `storage`：在本机保存过滤开关，不使用云端设置同步。
- `scripting`：注入内容脚本、用户级 CSS，并在腾讯页面注册渲染前的 MAIN 世界脚本。
- 站点权限仅包含 `https://v.qq.com/*`、`https://www.iqiyi.com/*`、`https://iqiyi.com/*`，未申请所有网站权限或 activeTab。
- 当前扩展代码未包含分析统计上报、账号登录或向开发者服务器上传数据的逻辑。轮播功能在网页内处理网站原有响应，不额外获取整页数据。
- 点击“复制排查报告”才会生成详细结构诊断，并尝试写入剪贴板；失败时可手动复制。报告不会自动发送。
- 报告包含扩展及脚本版本、站点标识、开关状态、容器和视频计数、分类统计、候选元素及祖先的标签名与类名、iframe 和开放 Shadow Root 数量。候选项也可能包含普通宽图链接周围的结构，不代表已确认广告。
- 诊断代码不输出链接地址、页面正文或 Cookie。元素类名来自网页，分享报告前仍应自行检查；不要附带账号信息或浏览器个人数据。

## 问题反馈

如有漏拦或正常内容受影响，请提供：浏览器名称与版本、扩展登记版本和页面脚本版本、发生问题的页面类型、复现步骤，以及手动复制的排查报告。截图请遮盖个人信息；若提供页面地址，请移除个人或认证参数。

“匹配”“已隐藏”是已识别的 DOM 容器数，可能包含预加载、空或嵌套容器，不是广告曝光数，也不包含腾讯轮播响应中移除的广告项。零匹配不能证明没有广告，已连接也不能证明全部广告已处理。

## 开发与验证

```powershell
npm install
npx playwright install chromium
npm test
node tests/focus-data.cjs
```

- `npm test`：加载真实扩展 API、使用本地页面夹具的浏览器回归测试。
- `node tests/focus-data.cjs`：腾讯轮播响应过滤专项，覆盖 fetch、XHR、响应克隆和导航后的开关状态。
- `node tests/audit-iqiyi.cjs`：可选的爱奇艺真实首页审计，会访问线上页面并在 `test-results/` 写入报告。未投放某类广告时不能判为该类验证通过。

可用 `PLAYWRIGHT_MODULE_PATH` 指定已有 Playwright 模块，用 `CLEARPLAY_BROWSER_PATH` 指定支持命令行加载扩展的 Chromium / Edge。测试浏览器对扩展加载方式的支持需以实际运行结果为准。

## 文件结构

- `manifest.json`：版本、权限及自动注入配置。
- `background.js`：用户级样式注入与腾讯轮播脚本注册。
- `content.js` / `content.css`：广告识别、隐藏、媒体处理、布局恢复及诊断。
- `tencent-focus.js`：腾讯轮播响应过滤，在页面 MAIN 世界运行。
- `popup.html` / `popup.js` / `popup.css`：开关、连接修复、版本显示与诊断界面。
- `tests/`：回归、轮播专项和线上审计脚本。
- `test-results/`：本地测试产物，由 .gitignore 排除，不上传。
